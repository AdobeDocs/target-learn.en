# Most-viewed by profile attribute based recommendations

This video demonstrates how to use Adobe Target's Most Viewed by Profile Attribute feature to deliver localized, segment-specific recommendations instead of a one-size-fits-all popularity list. By setting up a simple profile script (using the required rexattribute\_ prefix) and selecting the profile-attribute popularity algorithm, businesses can dynamically tailor "most viewed" content based on attributes like user country, subscription tier, or demographic.
